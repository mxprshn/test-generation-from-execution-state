- Probe kinds: method and constructor (`method: new`), points `entry`, `exit`, `exception`; line
  (`line: [...]`, no `at`); call site (`call: {...}`), points `before`, `after`, `exception`.
- `class` is a fully qualified name or a wildcard ('com.shop.*Service'); `subtypes: true` also matches
  subclasses and implementations. `method` without `params` covers every overload; `params: [String, int]`
  selects overloads by parameter types written as in the source.
- `when` and `what` are CEL expressions over `this`, `args` (`args[0]`, ...), `vars.<name>` (parameters
  and local variables by source name), `ret` (at `exit`, `after`), `exception`, `duration` (ms) and, at a
  call site, `call.target` and `call.args`. A `what` item is a bare expression, keyed by its text, or
  `name: expression`. Quote expressions that contain YAML special characters.
- Values are read from fields; program methods never run. JDK strings, numbers, `BigDecimal`,
  `java.time` types, enums, collections, maps and arrays are shown as plain values; other objects by their
  type and fields.
- `vars` needs classes compiled with `-parameters` or `-g`; local variables at a line need `-g`. An item
  that does not exist at a point is left out of that record; a key with `null` means the value was null.
- `limits` (defaults): `depth` 3 (levels of object fields), `items` 100, `string` 1000, `fields` 50,
  `max_hits` 1000 (hits after which a probe stops firing). A value cut by a limit is marked in
  the view (below).
- The compact view starts with a legend line, the hits per probe and point (`probe@point N`), placement
  warnings and errors, the end of the run with `code`, the exit code of the scenario, and the number of
  executions. Then each distinct execution of a probed method is shown once as a tree: the method with
  the values captured at entry ((no entry record) if `entry` is not probed); indented under it, the probed
  methods it called, the calls captured by call-site probes (→ call ⇒ result) and line probes (`L42 ...`);
  and its outcome (⇒ value, ⇒ threw, or ⇒ returned when `ret` is not captured). Identical executions and
  identical lines are shown once with ×N. Types are simple names; a map entry with a key that is not text
  is key: value. A longer value is labelled where it first occurs, Order#1{id: 1, ...}, and written
  Order#1 (#1 for a list) later; Order#3=#1+{id: 2, note: ∅} is a value like #1 except these fields
  (∅: field absent). Order{…} is an object cut by a limit, "abc…"(1200 chars) a cut string, [...]…+5 a
  cut collection; Order^1{...} and ^1 mark an object met twice within one captured value; <error: ...> a
  value that could not be read.
