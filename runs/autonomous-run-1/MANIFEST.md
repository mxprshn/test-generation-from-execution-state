# autonomous-run-1

The full run of the `autonomous` mode (docs/autonomous-mode.md): the 70 cases of the study and the 31 cases of
`cases/tools-projects.csv` (docs/tools-projects.md), two rounds each. Only `autonomous` was generated; the cells of
the other modes are the published ones of the release `v2-results` and are combined with this run for the tables.

## Code and settings

- Every cell was generated and evaluated on the commit `72ea6a72ede8d9ba76ef2859f3a739b2fa73215d`, tag
  `autonomous-run-1`; `scripts/run-lane.sh`'s guard refused to start unless the repository was a clean checkout of
  the tag. Later commits on the branch (this directory, README) do not change `runner/`, `pi/`, `prompts/` or
  `evaluation/`.
- Settings as in the v2 run (`results/provenance/lane-configs/all.yaml` of `v2-results`): model `OpenAI/gpt-6.1-sol`,
  thinking `medium`, 600 s per agent cell, `command_timeout` 900 s, rounds 1 and 2, `reference_runs` 2,
  `trace_depth` 5; Pi 0.84.1, Node 22.17.0, Maven 3.9.10. Mode-specific: `debug_runs` 3.
- The 70 cases: JDK 21.0.12.1, references = the released ones (byte-identical copy). The 31 cases: JDK 11.0.32.1
  (`jdk: 11`), references recorded on the tag before the run.
- Two processes over disjoint projects, two cells each (`parallel_cases: 2`), i.e. up to 4 cells at once:
  `configs/lane-a.yaml`, `lane-b.yaml` (70 cases), `tp-lane-a.yaml`, `tp-lane-b.yaml` (31 cases), produced by
  `scripts/make_lanes.py` from `configs/config.yaml` and `config-tools-projects.yaml`; they differ from those only
  by the case list, the work directory, the port range of the debugger and `parallel_cases`.
- Evaluation steps of the run: `verify`, `rq1`, `quality`. **RQ2 (PIT) is not computed yet**: the cells have no
  `rq2` record; `scripts/eval-pit.sh` adds it later without regenerating or re-tracing a cell (the hashes of the
  generation and of the other steps do not depend on the list of steps).
- Absolute paths in the copies here and in the archives are redacted as in `v2-results` (`/<root>`, `/<home>`,
  `<host>`, the provider's address, the key variables → `TESTGEN_API_KEY[_FALLBACK]`).

## Unpack and aggregate with v2

```bash
mkdir -p results/v2 results/autonomous-v2 results/autonomous-tools-projects
tar -xzf results.tar.gz -C results/v2                                   # v2-results
tar -xzf autonomous-v2.tar.gz -C results/autonomous-v2
tar -xzf autonomous-tools-projects.tar.gz -C results/autonomous-tools-projects
python3 scripts/combine_results.py results/combined results/v2 results/autonomous-v2
# config: settings of configs/config.yaml, paths.results: results/combined,
#         modes: [baseline, dump, rendered, autonomous], once_modes: [rendered-raw]
python3 -m evaluation.aggregate --config combined.yaml                  # -> results/combined/report
# the 31 cases alone: settings of configs/tp-lane-a.yaml, paths.results: results/autonomous-tools-projects, cases: []
python3 -m evaluation.aggregate --config tools-projects.yaml
```

Checked on the archives: 648 cells combined (508 of v2 + 140), `evaluation.aggregate` exits 0 for both; RQ1 by
mode (case means S/A/B/C): autonomous 0.986 / 0.893 / 0.629 / 0.286 over 70 cases; the 31 cases 1.0 / 0.919 /
0.532 / 0.306. RQ2 is empty for `autonomous` until `eval-pit.sh` has run.
